## Manutenção do README

Este repositório tem um README.md que serve como fonte de verdade do projeto (stack, telas, fluxos, pendências e bugs conhecidos). Mantenha-o atualizado:

- Ao concluir um item das seções "Pendências" ou "Bugs conhecidos" do README, atualize o README na mesma tarefa — remova ou marque o item como resolvido e ajuste qualquer seção afetada (ex.: mova de "Pendências" para "Concluído").
- Ao criar uma tela/rota nova, adicione-a ao mapa de rotas do README.
- Ao integrar um serviço ou mudar um fluxo principal, reflita a mudança na seção correspondente.
- Não é necessário atualizar o README para mudanças cosméticas (ajuste de cor, texto de botão, refactor interno sem impacto no comportamento).
